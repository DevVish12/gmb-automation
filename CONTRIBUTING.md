# Contributing to gmb-automation

Thanks for your interest. This is a small, maintainer-led project.

## How to contribute

1. Fork the repo and create a branch from `main`.
2. Keep changes small and focused; add or update tests where they exist.
3. Run the app locally before opening a pull request (see README).
4. Open a pull request with a short description of what changed and why.

## What not to commit

Never commit secrets: no API keys, OAuth tokens, `.env` files, databases
(`*.db`), or client credentials. The `.gitignore` already excludes these —
check before pushing.

## Reporting issues

Open a GitHub issue with steps to reproduce, what you expected, and what
happened instead. Screenshots help.
